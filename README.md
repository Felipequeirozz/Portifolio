## Descrição do projeto

Este projeto consiste no desenvolvimento de um portfólio digital pessoal, criado para apresentar minha trajetória acadêmica, habilidades, experiências e projetos desenvolvidos durante meus estudos.

O objetivo é organizar minhas informações de maneira visual, acessível e profissional, permitindo acompanhar meu desenvolvimento pessoal e profissional na área de tecnologia.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript

## Como acessar

O portfólio está disponível online e pode ser acessado diretamente pelo navegador através do GitHub Pages.

## Estrutura e funcionamento

O site está organizado nas seguintes seções:

- **Perfil:** apresentação pessoal e informações acadêmicas.
- **Habilidades:** conhecimentos e competências.
- **Projetos:** apresentação dos trabalhos desenvolvidos.
- **Documentação:** informações e arquivos relacionados aos projetos.
- **Contato:** formas de entrar em contato e acessar minhas redes profissionais.

## Projetos apresentados

### 1. Atendimento ao Cliente
Projeto desenvolvido com base em uma pesquisa realizada com 50 entrevistados, apresentando informações e resultados coletados.

### 2. Gerenciador de Sites
Página destinada à organização de sites favoritos, separados entre categorias pessoais e profissionais.

### 3. Primeiro Projeto
Desenvolvimento de uma calculadora para estimar consumo de energia e seus respectivos custos.

## Recursos adicionais

O portfólio conta com recursos visuais para melhorar a experiência de navegação:

- Animações de entrada dos elementos.
- Efeitos visuais ao passar o mouse sobre os cartões.
- Rolagem suave entre as seções.
- Layout adaptável para diferentes tamanhos de tela.

## Implementação dos recursos

Os recursos visuais foram desenvolvidos utilizando principalmente CSS3.

Algumas propriedades utilizadas:

- `animation` e `@keyframes`: criação de animações.
- `transition`: transições suaves.
- `transform`: modificações de posição e escala.
- `box-shadow`: criação de sombras.
- `:hover`: efeitos ao passar o mouse.
- `scroll-behavior`: rolagem suave da página.
