## Sobre o projeto

Este repositório apresenta meu portfólio digital, desenvolvido para reunir informações sobre minha formação acadêmica, conhecimentos técnicos, experiências e projetos.

O site foi construído utilizando HTML, CSS e Bootstrap, com foco em organização, responsividade e facilidade de navegação.

## Sobre mim

Meu nome é **Felipe Queiroz** e sou estudante da ETEC Antônio Furlan, onde curso o Ensino Médio Integrado ao Técnico em Contabilidade. Também estudo Desenvolvimento de Sistemas e Transações Imobiliárias.

Tenho interesse em tecnologia, programação e desenvolvimento profissional. Busco ampliar meus conhecimentos por meio de atividades práticas e projetos que contribuam para minha formação.

## Como executar

**1.** Clone o repositório:

```bash
git clone https://github.com/Felipequeirozz/SEU-REPOSITORIO.git
```

**2.** Abra a pasta do projeto no Visual Studio Code.

**3.** Confira se os arquivos estão organizados desta forma:

```text
Meu-Portfolio/
│
├── imagens/
│   └── foto_perfil.jpeg
│
├── index.html
├── reset.css
├── estilo.css
└── README.md
```

**4.** Abra o arquivo `index.html` no navegador para visualizar o site.
